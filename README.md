# groomer-assistant

Личный Telegram-помощник грумера Pretty Dogs: карточки питомцев, расписание, фотографии, история визитов и учёт заработка.

## Веб-приложение

Веб-интерфейс доступен на корневом адресе Worker `/` и по адресу `/app`. Это отдельный адаптивный интерфейс, который работает с той же базой D1, что и Telegram-бот.

- **Обзор** — очередь на сегодня, статус визитов и заработок.
- **Питомцы** — поиск, визуальные карточки, редактирование данных, карта стрижки и фотографии для разрешённых пород.
- **Визиты** — недавняя история, выполненные услуги, длительность и начисления.
- **Заработок** — итоги за сегодня, месяц и расчётные половины месяца.

Приложение сохраняет Telegram Mini App-вход для запуска из бота и поддерживает отдельный пароль для обычного браузера.

### Настроить отдельный веб-вход

Перед входом через обычный браузер добавь в Cloudflare Worker `groomer-assistant` секрет `WEB_APP_PASSWORD`.

1. Открой Cloudflare → **Workers & Pages** → `groomer-assistant` → **Settings** → **Variables and Secrets**.
2. Добавь переменную типа **Secret** с именем `WEB_APP_PASSWORD`.
3. Задай длинный уникальный пароль (не менее 16 символов; лучше использовать случайную комбинацию). Не добавляй его в GitHub или `wrangler.toml`.
4. Опубликуй актуальный Worker.

Веб-сессия действует 24 часа. Секрет используется сервером для проверки пароля и подписи сессии; в браузер секрет не передаётся.

## Worker и база данных

- Worker entry point: `src/index.js`
- HTML/CSS/JS веб-приложения: `src/web-app.js`
- D1 binding: `DB`
- Scheduled trigger: раз в минуту

Настройки D1 и cron находятся в `wrangler.toml`. Токены и пароли должны храниться в Cloudflare Secrets, а не в репозитории.
