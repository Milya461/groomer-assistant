# groomer-assistant

Веб-приложение Pretty Dogs для рабочего процесса грумера: календарь и смены, очередь, карточки питомцев, карта стрижки, фото, история визитов и учёт заработка.

## Веб-приложение

Приложение открывается в обычном браузере по корневому адресу Worker `/` или `/app`. Оно больше не требует запуска через Telegram и использует D1 для данных и оптимизированных фотографий.

- **Главное** — очередь на сегодня, статусы визитов, заработок и создание записей.
- **Календарь** — рабочие дни, часы смен, записи на выбранную дату, создание, редактирование и перенос будущих записей.
- **Питомцы** — карточки, данные питомца, главное фото, карта стрижки и фото-примеры.
- **Визиты** — история, выполненные услуги, длительность и фото после визита.
- **Доход** — итоги за день, месяц и половины месяца.

## Карточки пород и расчёт стоимости визита

В карточке питомца поле **«Размер / разновидность по прайсу»** появляется только для пород, которым в прайсе нужны дополнительные варианты. Размер/тип шерсти сохраняется в карточке, чтобы при следующих визитах повторно его не спрашивать.

При завершении визита приложение загружает услуги по породе и сохранённой разновидности. Нужно выбрать одну основную услугу и, если они были, дополнительные услуги. Цены подставляются из каталога, но каждую строку и общую сумму можно изменить. Перед сохранением показывается итоговая сумма и предварительный заработок; записи о заработке и визит завершаются только после кнопки **«Подтвердить сумму и завершить визит»**.

В дополнительные услуги внесены:
- Премиум СПА-уход — 1 100 ₽ для маленьких и средних питомцев.
- Дерма СПА-уход — 600 ₽ для маленьких, 700 ₽ для средних.
- Дополнительный уход по типу шерсти — 600 ₽ для маленьких, 1 000 ₽ для средних.
- Профилактическая чистка зубов — стартовая цена 450 ₽, редактируемая, потому что часть суммы на исходном изображении закрыта.
- Уход за подушечками лап — 300 ₽.

У шпица в каталоге предусмотрены только «Гигиена» и «По красивой» с ценами по сохранённому размеру. Варианта «Под машинку» нет. Для бульдога сохранён диапазон 3 100–3 600 ₽, остальные строки редактируются в форме завершения визита при необходимости.

## Иконка на экран «Домой» iPhone

Для ярлыка Safari настроена отдельная иконка из фото двух котов: файл `icons/apple-touch-icon.png`. Worker обслуживает её по адресу `/apple-touch-icon-v1.png`, а `/manifest.webmanifest` задаёт имя Pretty Dogs и запуск в режиме standalone.

После публикации Worker удали прежний серый ярлык с экрана «Домой», открой сайт заново в Safari, нажми «Поделиться» → «На экран Домой» и добавь ярлык повторно. iPhone может сохранять старую иконку в кэше старого ярлыка.

## Создание новой карточки прямо из записи

В поле «Питомец» доступен пункт **«Новый питомец — создать карточку»**. После выбора укажи имя и при необходимости породу; если для породы нужен размер или разновидность, выбери её для правильного прайса. При сохранении записи приложение создаёт полноценную постоянную карточку питомца в D1. Она появится в разделе «Питомцы» и будет доступна для следующих визитов. Для прежних временных записей при редактировании также можно сохранить полноценную карточку.

## Первичная настройка

### 1. Хранение фотографий

Отдельный R2 bucket не требуется: фотографии, загруженные в веб-приложении, уменьшаются в браузере и сохраняются в D1. Это позволяет публиковать приложение без настройки дополнительных ресурсов Cloudflare. Если фотография превышает допустимый размер, приложение автоматически пытается уменьшить её перед загрузкой.

### 2. Настроить пароль

1. Открой Cloudflare → **Workers & Pages** → `groomer-assistant` → **Settings** → **Variables and Secrets**.
2. Добавь Secret с именем `WEB_APP_PASSWORD`.
3. Задай длинный уникальный пароль не менее 16 символов. Не добавляй его в GitHub или `wrangler.toml`.
4. Убедись, что Worker опубликован.

Веб-сессия действует 30 дней. Вход выполняется в обычном браузере; Telegram SDK для авторизации не используется.

## Фотографии без Telegram

Перенос Telegram-фотографий не используется. Новые фото главного изображения питомца, примеры для карты стрижки и фото после визита загружаются напрямую через веб-приложение, сжимаются в браузере и хранятся в D1. Telegram-бот, `BOT_TOKEN` и R2 bucket не нужны для фото.

## Файлы и ресурсы

- Worker entry point: `src/index.js`
- HTML/CSS/JS веб-приложения: `src/web-app.js`
- D1 binding: `DB`
- Фото хранятся в D1 как оптимизированные изображения.

Планировщик Telegram-напоминаний отключён. Секрет `WEB_APP_PASSWORD` должен храниться в Cloudflare Secrets, не в репозитории.
